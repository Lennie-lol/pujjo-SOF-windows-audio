# Research and provenance — 2026-11-17

Primary references used for this implementation:

- [SOF firmware repository](https://github.com/thesofproject/sof-bin), file `v2.12.x/sof-ipc4-v2.12/adl-n/intel-signed/sof-adl-n.ri`, Git blob `47bb69dd2e22435e6da37ccee17103e0f6452638`. Size 707036 bytes; SHA256 `bc83cffa1bb5a4a8da24bbc7bb7040bd744f1e0c63e3d16151d1769ac8ae8214`. Obtained through GitHub and parsed with production parser body under ASan/UBSan. $AE1 length2524/version1.0; payload704512; $AM1 length52, ADSPFW2.12.0.1,25 modules. Exact file hash records provenance, not authentication or board compatibility. Firmware bytes are deliberately not included.
- [rimage manifest declarations](https://github.com/thesofproject/rimage/blob/main/src/include/rimage/sof/user/manifest.h), Git blob `d270ce98b309e629a5bbdcc7f8e3fc0c8137ee3e`: $AM1 and $AME IDs and module/configuration layout facts.
- [SOF boot documentation](https://thesofproject.github.io/latest/developer_guides/firmware/boot.html) and [SOF documentation](https://thesofproject.github.io/latest/): distinguish signed firmware boot from IPC and topology. No Linux topology was assumed Windows-compatible.
- [Microsoft WdfWaitLockAcquire](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdfsync/nf-wdfsync-wdfwaitlockacquire): NULL timeout acquisition requires PASSIVE_LEVEL; lock does not raise IRQL. Persistent device-parented lock protects synchronous target lifetime.
- [Microsoft common buffers](https://learn.microsoft.com/en-us/windows-hardware/drivers/wdf/using-common-buffers) and [logical address API](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdfcommonbuffer/nf-wdfcommonbuffer-wdfcommonbuffergetalignedlogicaladdress): device logical addresses must come from the DMA framework.
- [Microsoft driver model properties](https://learn.microsoft.com/en-us/windows-hardware/drivers/develop/driver-model-settings-properties-for-driver-projects), [KMDF version history](https://learn.microsoft.com/en-us/windows-hardware/drivers/wdf/kmdf-version-history), [driver samples](https://github.com/microsoft/Windows-driver-samples): standard WDK/KMDF build/startup instead of a desktop application with a custom entry wrapper.
- [Public RT5682S driver](https://github.com/coolstar/rt5682s): rt5682s.c blob `1c14479e640c8ad1d25d16db44d8372bdc34da60`, registers.h blob `04c981cfc698084d36403b3f381e3e91a27354c7`. Inspected license identifies Apache-2.0 CoolStar portions and MS-PL Microsoft sample portions. No implementation file was copied. Independent BSD-3-Clause planner uses register/bit-field facts and the three direct MCLK-to-24.576MHz conversion tuples (M,N,K):19.2MHz=(2,6,3),24MHz=(3,6,3),48MHz=(8,6,3). These coefficients and the source's board-specific calibration cannot establish Pujjo electrical correctness. No GPL-only Linux codec implementation was copied into Windows code.

Retained project licenses and upstream checksums govern existing bundled source. The existing Linux rt1015p-family references remain the relevant RTL1019P family; rt1019.c is not substituted for it. Register facts are research evidence, not permission to power a device.
