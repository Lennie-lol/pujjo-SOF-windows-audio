# NHLT evidence handling

The Windows NHLT parser now rejects truncated endpoint arrays, invalid checksum, overflowing vendor records, and SoundWire inventories beyond the destination array. It validates each declared format record and treats absent formats as unknown instead of inventing channel/rate/bit-depth defaults. The legacy SoundWire enumerator no longer fabricates Realtek ALC722 children when firmware evidence is absent, and ignores incomplete endpoint identities. These checks are hardware-free and do not establish the actual SSP wiring or formats on a Pujjo board. The tests execute the source parser against synthetic packed tables; Windows ABI and target table validation remain separate requirements. No actual DSP boot or speaker/codec/amp activation is enabled.
